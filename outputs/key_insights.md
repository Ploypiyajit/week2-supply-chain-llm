# Key Insights

- More complex prompting does not automatically produce better results.
- Zero-Shot, Few-Shot, CoT, and ToT each have different strengths.
- LLM-as-Judge is useful for comparison but should not be treated as ground truth.
- Temperature controls variation, not quality or length.
- Max Tokens sets the response ceiling and can cause truncation if too low.
- Top-p controls the breadth of candidate token selection.
- Stakeholder-specific parameter tuning changes the usefulness of the report.
- LLM-generated analytics should be verified using deterministic tools such as pandas or SQL.
